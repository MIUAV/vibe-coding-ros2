# # 🚨 Mandatory rule (Violation = Code not available)
# # # Rule 1: CMake Export 3-in-1
Each time `ament_target_dependencies` is written, * * must * * be followed by:

```cmake
ament_export_dependencies(rclcpp std_msgs)              # [REQUIRED]
ament_export_include_directories(include)                 # [REQUIRED when include/ dir exists]
ament_export_libraries(${PROJECT_NAME})                  # [REQUIRED]
```
* * Missing Consequences * *: `undefined reference` link error, 100% compilation failed.
# # # Rule 2: LifecycleNode for production nodes
| Scenario | Node Type | Reason ||------|---------|------|| Robot Control, Navigation, Sensor Management | `rclcpp_lifecycle:: LifecycleNode' | Elegant start and stop required || Temporary tool nodes, one-time scripts | `rclcpp:: Node` | Rapid development |
# # # Rule 3: QoS combinations are correct

```cpp
// Control commands (cmd_vel) — must be reliable
QoS(10).reliable()              // ✅

// Sensor data (camera/lidar) - allow dropped frames
QoS(10).best_effort()           // ✅

// Lifecycle state broadcast → new subscribers receive latest value
QoS(10).transient_local()       // ✅
```
# # # Rule 4: File creation order

```
package.xml → CMakeLists.txt → include/*.hpp → src/*.cpp → launch/*.py
```
