# biped-walk Case — 双足机器人步行控制

## 背景

双足机器人步行是 robotics 领域的核心难题，涉及平衡控制、ZMP（Zero-Moment Point）稳定性、步态周期规划。本案例展示如何使用 ROS2 生成稳定的双足步行轨迹。

**应用场景：**
- 人形机器人整周步行
- 不平整地形适应
- 上下楼梯

---

## 用户需求

```
用户：让双足机器人从 (0,0,0) 走到 (3,0,0)，保持步行周期 1.2s，步长 0.3m
```

---

## 技术方案

### ZMP 稳定性判据

```
ZMP 在支撑多边形内 → 机器人稳定
ZMP 超出支撑多边形 → 机器人倾倒
```

### 步态周期

```
T_total = 1.2s
T_single_support = 0.8s  # 单脚支撑
T_double_support = 0.4s  # 双脚支撑
step_length = 0.3m
```
