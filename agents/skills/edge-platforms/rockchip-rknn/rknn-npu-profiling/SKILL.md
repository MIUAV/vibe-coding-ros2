# RKNN NPU 性能分析技能

> 分析和优化瑞芯微NPU推理性能

## 何时使用

- 性能瓶颈分析
- 算力利用率监控
- 优化建议获取

## 工具

- **rknn-toolkit2**: 模型分析
- **rockx**: 算子性能分析
- **adb**: 设备端调试

## 性能指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 算力利用率 | >70% | NPU使用率 |
| 内存带宽 | <50% | DDR带宽占用 |
| 推理延迟 | <50ms | 单帧处理时间 |

## 优化策略

1. 算子融合
2. 内存布局优化
3. 批量处理
4. 流水线并行
