# Skills

> 可直接在 AI 开发中使用的模块化技能

---

## 可用技能

### ROS2 包生成器

**路径**: `./ros2-package-generator/SKILL.md`

**功能**: 生成完整的 ROS2 功能包结构

**触发词**: "创建一个 ROS2 包" / "generate ros2 package"

---

### ARM64 交叉编译

**路径**: `./arm64-cross-compile/SKILL.md`

**功能**: 配置 x86 到 ARM64 交叉编译环境

**触发词**: "交叉编译 ARM" / "cross compile ARM"

---

### ROS2 调试

**路径**: `./ros2-debugging/SKILL.md`

**功能**: ROS2 节点调试、话题分析、bag 回放

**触发词**: "调试 ROS2" / "ros2 debug"

---

## 使用方法

### VS Code Copilot

```
# 在对话中使用
@skills/ros2-package-generator 创建新的感知包
```

### Cursor

```
# 使用快捷命令
/ros2-create-pkg
```
